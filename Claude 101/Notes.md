## What the Course Is About

Claude 101 is the entry-point course for anyone using Claude as an everyday tool — not for developers building with the API, but for people who just want to get real work done faster and better with Claude in the chat interface. It covers the practical basics: what Claude is, what it's good for, and how to actually use its core features well.

## Key Concepts

### 1. What Claude Is (and Isn't)
- An AI assistant for reasoning, writing, analysis, and problem-solving through conversation
- Not a search engine — it reasons over what it knows and what's given to it, rather than just retrieving facts
- Works best as a thinking partner and drafting tool, not a black-box oracle

### 2. Core Features
- **Conversations** — multi-turn, follow-up-friendly chat rather than one-shot Q&A
- **Projects** — organizing related chats and files together with shared context/instructions
- **Artifacts** — generating standalone content (documents, code, visuals) that can be viewed and iterated on separately from the conversation
- **File uploads** — giving Claude documents, spreadsheets, or images to work from directly
- **Styles/preferences** — adjusting tone and format so responses match how you actually want to work

### 3. Everyday Use Cases
- Drafting and editing writing (emails, reports, summaries)
- Brainstorming and structuring ideas
- Analyzing and summarizing documents or data
- Research support and explaining unfamiliar topics
- Light coding and technical troubleshooting help

### 4. Getting Better Results
- Being specific about the goal, audience, and format you want
- Giving Claude relevant context up front instead of assuming it "just knows"
- Iterating — treating the first response as a draft to refine, not a final answer
- Breaking large or ambiguous tasks into smaller, clearer requests

## What I Learned

- Most of the value from Claude comes from *how* you frame a task, not from any hidden trick — clear goals and context beat clever prompts.
- Claude works best as an iterative collaborator: give it something, react to what it produces, refine.
- Knowing the basic feature set (Projects, Artifacts, file uploads) unlocks a lot of everyday usefulness beyond a plain chat box.
- This course is the on-ramp — it's meant to be paired with a role-specific course (AI Fluency, Claude Code, etc.) once you know what kind of work you want Claude to help with.

## One-Line Takeaway
> Claude is most useful as an iterative collaborator — the biggest lever isn't the tool's power, it's how clearly you set up the task.
