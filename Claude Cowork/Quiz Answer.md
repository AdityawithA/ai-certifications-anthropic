# Quiz Answers

## Question 1
**Which of these tasks is the best fit for Cowork?**

- Brainstorming names for a new project with Claude
- Summarizing a single PDF you've uploaded into the chat
- ✅ Reading a folder of last month's meeting notes and saving a one-page summary back into it
- Fixing a bug in your team's codebase and running the tests

---

## Question 2
**When you connect a working folder in Cowork, what can Claude do with it?**

- Read the files in it, but not make any changes
- See file names only, not their contents
- Access every folder on your computer from that point on
- ✅ Read and write files in that folder (and it asks before deleting)

---

## Question 3
**A good Cowork prompt typically names which three things?**

- ✅ The deliverable you want, the inputs to use, and any nuance like audience or format
- Your name, your team, and your deadline
- The model, the temperature, and the token limit
- A greeting, the question, and a thank-you

## Question 4
**Claude is partway through a task when you realize it's working from the wrong template. What's the best next step?**

- Wait for it to finish, then start over in a new conversation
- ✅ Tell Claude now and direct it to the right template
- Close the app to stop the task
- You can't change direction once a task has started

## Question 5
**In the default permission mode, which of these actions will Claude pause and ask you to confirm before taking?**

- Reading a file in your connected folder
- Searching a SharePoint site via the M365 connector
- ✅ Sending a Slack message it drafted
- Showing you its plan for a task

---

## Question 6
**What's the main difference between global instructions and project instructions in Cowork?**

- ✅ Global instructions apply to every Cowork session; project instructions apply only inside that project
- Global instructions are set by your admin; project instructions are set by you
- Global instructions are permanent; project instructions reset every session
- There's no difference — they're two names for the same setting

---

## Question 7
**You've set up a scheduled task while running Cowork in the cloud. What needs to be true for it to run at its set time?**

- You're in the conversation watching it
- ✅ Nothing more — the task runs in the cloud at its set time
- You're on an Enterprise plan
- The Claude desktop app is open and your computer is awake

---

## Question 8
**Which statement best describes the relationship between skills and plugins?**

- They're two names for the same thing
- Skills work in Cowork; plugins only work in Claude Code
- ✅ A plugin bundles skills together so they can be installed in one package
- Plugins are built by Anthropic; skills are built by users

---

## Question 9
**What does Claude in Chrome add to Cowork?**

- It lets Claude write and run code in the browser
- ✅ It lets Claude read and act on web pages in your browser
- It's required before you can run any Cowork task
- It replaces the need for connectors entirely

---

## Question 10
**What's the recommended habit before you send, publish, or act on something Claude produced in Cowork?**

- ✅ Review it yourself — Claude accelerates the work, but you own the judgment
- Ask Claude whether it's correct
- Run it through a second Cowork session to double-check
- Nothing extra — Cowork outputs are ready to ship as-is
